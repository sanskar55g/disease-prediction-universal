Universal Disease Prediction

An AI-Assisted Framework for Disease Prediction and Health Guidance

About Objectives Features Technologies Workflow

About the Project

Universal Disease Prediction is a healthcare-focused project designed to analyze user-reported symptoms and available medical history to support disease prediction.

The system uses a multi-tier prediction approach and an orchestration layer to process patient information and provide relevant health guidance.

Project Objectives

  • Analyze symptoms provided by users.
  • Use available medical history during assessment.

Technologies Used

  • Frontend: HTML, CSS and JavaScript
  • Backend: Python and FastAPI
  • AI Integration: Groq API
  • Development Tools: Git, GitHub and VS Code

System Workflow

  1. The user enters symptoms and relevant health information.
  2. The system processes the available patient information.
  3. The orchestration layer determines the appropriate prediction path.
  4. The prediction system generates an assessment.
  5. The user receives the result and relevant health guidance.
  6. The user can ask follow-up questions about the result.

Limitations

Predictions depend on the quality of the available information and the capabilities of the underlying models. Results are intended for informational support and are not a substitute for professional medical diagnosis.
